# 🔍 Fraud Detection System using Machine Learning 🚀

## 🌟 Overview  
This is a **Fraud Prediction System** that uses **Machine Learning** to detect fraudulent transactions.  
The project is built using:  
- 🎨 **Frontend:** HTML, CSS  
- 🖥️ **Backend:** Python, Flask  
- 🧠 **Machine Learning Model:** Random Forest  
- ☁️ **Database:** MongoDB Atlas  
- 🚀 **Deployment:** Render  

## 🎯 Features  
✅ Predicts fraud based on user input  
✅ Stores transaction data in **MongoDB Atlas**  
✅ User-friendly interface with attractive UI  
✅ Deployed on **Render** for easy accessibility

## 🛠️ Installation & Usage  

### 🔹 Step 1: Clone the Repository  

git clone https://github.com/sheetalguptaa/fraud-detection.git
cd fraud-detection

## 🔹 Step 2: Install Dependencies

pip install -r requirements.txt

## 🔹 Step 3: Run the Application

python app.py

Visit http://127.0.0.1:5000/ in your browser.
